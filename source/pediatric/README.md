# pediatric 教室維護原始碼

正式網站與操作說明見根目錄 README.md。保留本目錄模型、來源及授權。

## 兒童系統篩選修正（2026-10-29）

PIPER 的系統按鈕與教學區系統下拉選單現在同步篩選模型，構造清單及逐件顯示只列目前系統。「恢復本系統」不會打開其他系統；重開目前來源模型也保留系統選擇。載入期間切換系統會沿用最新選擇。

同一構造的 2D／3D 表面預設擇一，神經系統預設顯示大腦皮質與小腦；填充軟組織、計算用封口及來源未提供的構造不以其他器官代替。內分泌與生殖系統保留文字教學。原始模型、分件及授權未修改。

## 兒科導覽精簡（2026-10-29）

依使用者要求移除「13 個月顱骨」、「匯入本機模型」與「目前匯入模型」入口，以及對應檔案選擇器與匯入提示。網站保留 PIPER 6 歲來源模型、系統篩選、嬰兒／兒童簡化示意與教學內容。顱骨不再打包或提供於線上網站；原始顱骨及授權留存於來源資料夾。

## 三系統醫學圖解修正（2026-10-29）

肌肉、消化與泌尿系統預設改為醫學來源原圖、中文構造導讀及正確通路。肌肉分全身／肌束、腹壁、上肢、大腿、小腿五組 OpenStax 原圖；消化與尿路使用 NIH／NIDDK 原圖。支援平移、滑鼠縮放、雙指縮放與鍵盤操作；離線檔同樣內嵌原圖。

PIPER 只有局部構造，保留於「6 歲來源 3D（局部）」，不把缺少腸道或完整尿路的網格當作完整系統。圖解是通用解剖，並非新取得的完整兒科 3D 或特定月齡掃描。圖片授權及來源見 source/pediatric/reference-images/provenance.json、models/ATTRIBUTION.md；查證摘要見 validation/medical-reference-audit.md。
